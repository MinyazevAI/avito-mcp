# avito-mcp — поиск на Авито для Claude Desktop

MCP-сервер, который даёт Claude Desktop инструменты для поиска на [Авито](https://www.avito.ru). Вы пишете обычный запрос, а Claude сам:

- выбирает город и категорию;
- выставляет фильтры в форме поиска Авито;
- собирает выдачу и при необходимости открывает карточки;
- делает сравнительную таблицу.

Сайт открывается в отдельном окне Microsoft Edge со своим профилем, ваш обычный браузер не затрагивается. Работает в обычном чате Claude Desktop и в режиме Cowork.

> **Для личного использования.** Сервер только читает страницы, медленно и в видимом окне браузера. Правила Авито ограничивают автоматический доступ к сайту: пользуйтесь умеренно, соблюдение правил Авито — на вашей ответственности.

## Примеры запросов

В обычном чате Claude Desktop или в Cowork:

> Найди на Авито однокомнатные квартиры и студии в Казани, Кировский район, до 12 млн, от 30 м², дом не старше 20 лет. Сделай таблицу: адрес, цена, площадь, этаж, год постройки, цена за м², ссылка.

> Найди б/у iPhone 13 до 30 000 ₽ в Казани с Авито Доставкой. Покажи 10 самых дешёвых.

> Найди мастеров по ремонту стиральных машин в Казани, которые работают с Bosch. Сравни цены на диагностику.

> Вот ссылка на поиск Авито: ‹ссылка›. Собери объявления с первых двух страниц и отбери дома 2010 года и новее.

В Cowork можно сразу попросить сохранить результат в файл: «…и сохрани таблицу в avito-kvartiry.md».

## Требования

- Windows 10 или 11.
- [Python 3.10 или новее](https://www.python.org/downloads/). При установке отметьте **Add python.exe to PATH**.
- [Claude Desktop](https://claude.ai/download) — обычная версия или из Microsoft Store.
- Microsoft Edge (в Windows он уже есть). Отдельно скачивать браузер для Playwright не нужно.
- Интернет для первой установки зависимостей.

## Установка

### Вариант 1. Через git

```bat
git clone https://github.com/MinyazevAI/avito-mcp.git avito-mcp
cd avito-mcp
install.bat
```

### Вариант 2. Без git

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Распакуйте архив в простое место вне OneDrive, например `C:\avito-mcp`.
3. Дважды щёлкните `install.bat`.

### Что делает install.bat

- Находит Python 3.10+ (сначала `py -3`, затем `python`).
- Создаёт окружение `.venv` в папке проекта и ставит зависимости.
- Проверяет, что установлен Edge.
- Проверяет, что Claude Desktop закрыт. Если он открыт, просит закрыть его через значок в трее (у часов) → **Выход**.
- Прописывает сервер в `claude_desktop_config.json`, в обычной и MSIX-версии Claude Desktop. Меняется только запись `mcpServers.avito`, остальные настройки и серверы остаются как были. Рядом сохраняется резервная копия `claude_desktop_config.json.bak-ГГГГММДД-ЧЧММСС`.
- В конце запускает сервер и показывает список его инструментов. Окно браузера при этом не открывается.

Ключи (из командной строки в папке проекта):

| Команда | Что делает |
|---|---|
| `install.bat` | установить или обновить |
| `install.bat --yes` | то же без вопросов и без паузы в конце |
| `install.bat --uninstall` | удалить запись `avito` из конфига (с резервной копией) |
| `install.bat --config путь\к\файлу.json` | писать в указанный файл вместо настоящего конфига |

## Проверка в Claude Desktop

1. Запустите Claude Desktop. **Настройки → Разработчик**: сервер `avito` должен быть в статусе «running».
2. **Обычный чат.** Напишите один из запросов выше. При первом вызове Claude спросит разрешение на инструмент — выберите «Всегда разрешать», инструменты только читают сайт. Откроется отдельное окно Edge; не закрывайте его, пока Claude работает.
3. **Cowork.** Откройте режим Cowork и повторите запрос, добавив «сохрани таблицу в файл».

## Обновление и перенос

- **Обновление:** `git pull`, затем снова `install.bat`. Без git: скачайте ZIP заново, распакуйте поверх старой папки и запустите `install.bat`.
- **Перенос папки:** переместите её и снова запустите `install.bat` — он обновит путь в конфиге.

Повторный запуск `install.bat` безопасен в любой момент.

## Удаление

1. Закройте Claude Desktop и выполните `install.bat --uninstall`.
2. Удалите папку проекта.
3. Удалите папку профиля браузера `%USERPROFILE%\.avito-mcp`.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `avito_open_search(city, query, category, price_min, price_max, sort)` | Открывает выдачу. Возвращает ссылку, число объявлений, рубрику, группы фильтров |
| `avito_get_filters(url)` | Все фильтры страницы: тип, варианты, текущее значение |
| `avito_apply_filters(url, filters)` | Выставляет фильтры. Возвращает новую ссылку, `applied` и `not_applied` с причинами |
| `avito_set_location(url, district, metro, address, radius_km)` | Выставляет район, метро или адрес |
| `avito_search(url, pages, start_page)` | Собирает объявления, до 3 страниц за вызов |
| `avito_listing_details(urls)` | Подробности карточек, до 5 за вызов |

Все инструменты только читают сайт. Сервер не входит в аккаунт и ничего не отправляет: не нажимает «Написать», «Показать телефон», «Купить». Не собирает имена и телефоны продавцов и не обходит капчу.

## Если Авито показало проверку

Иногда Авито показывает «Доступ ограничен: проблема с IP» или капчу «я не робот».

1. Окно Edge выходит на передний план, а Claude просит вас пройти проверку.
2. Нажмите в окне «Продолжить», решите капчу и напишите Claude «готово» — он повторит запрос.
3. Пока вы решаете капчу, сервер первую минуту не перезагружает страницу, чтобы проверка не сбросилась.

Если проверка появляется снова сразу после прохождения, Авито временно ограничило доступ с вашего адреса:

- сделайте перерыв на 30–60 минут;
- выключите VPN;
- берите меньше страниц и карточек за раз;
- при необходимости увеличьте паузу `AVITO_MCP_DELAY` (см. «Настройки»).

## Логи

Логи сервера пишет Claude Desktop. Открыть папку: Win+R → вставьте путь → Enter.

- Версия из Microsoft Store: `%LOCALAPPDATA%\Packages\Claude_<код>\LocalCache\Roaming\Claude\logs\` (вместо `<код>` — набор букв, папка там одна).
- Обычная версия: `%APPDATA%\Claude\logs\`.

Нужные файлы: `mcp-server-avito.log` — журнал этого сервера, `mcp.log` — общий журнал подключения серверов.

## Частые проблемы

- **Инструментов avito нет в чате.**
  - Закройте Claude Desktop полностью через трей (значок Claude → Выход) и откройте снова.
  - Проверьте **Настройки → Разработчик**.
  - В чате откройте меню инструментов (значок ползунков или «+») и убедитесь, что `avito` включён.
- **Сервер в статусе ошибки.** Откройте `mcp-server-avito.log`. Часто помогает повторный запуск `install.bat`.
- **«Не найден Python 3.10 или новее».** Установите Python с python.org, отметив **Add python.exe to PATH**, и запустите `install.bat` снова.
- **Edge не найден.** Установите Edge или пропишите в блоке `env` конфига `"AVITO_MCP_BROWSER": "chrome"`.
- **Пустые ответы или `no_items`.** Возможно, Авито поменяло вёрстку. Разбор страниц — в `parsing.py` и `filters.py`, селекторы построены на атрибутах `data-marker`.

## Ограничения

- Работает неспешно: между загрузками страниц пауза 5 секунд, каждое изменение фильтра — около 3 секунд. Один вызов инструмента длится не больше ~45 секунд. Если не всё успело, Claude сам продолжит с того же места.
- Фильтры у каждой категории свои. Если нужного нет (например, у услуг нет фильтра цены), Claude отфильтрует результаты сам.
- «Производитель» и «Модель» выбираются поиском по названию: нужен вариант, который предлагает сам Авито.
- Радиус от адреса Авито предлагает не везде. Если его нет, инструмент вернёт `not_supported`.
- Корень некоторых разделов — витрина без выдачи. Тогда сервер вернёт список подкатегорий, и Claude выберет нужную.

## Настройки

Переменные окружения в блоке `"env"` записи `avito` в `claude_desktop_config.json`:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `AVITO_MCP_BROWSER` | `msedge` | Браузер: `msedge` или `chrome` (установленные в системе) |
| `AVITO_MCP_DELAY` | `5` | Пауза между загрузками страниц, секунд (не меньше 3) |
| `AVITO_MCP_PROFILE_DIR` | `%USERPROFILE%\.avito-mcp\browser-profile` | Папка профиля браузера |

После изменения конфига полностью перезапустите Claude Desktop.

## Для разработчика

- Модули:
  - `server.py` — точка входа и инструменты;
  - `browser.py` — Edge, паузы, проверки;
  - `catalog.py` — города, категории, ссылки;
  - `parsing.py` — выдача и карточки;
  - `filters.py` — панель фильтров;
  - `form.py` — выставление фильтров;
  - `location.py` — окно «Где искать».
- Тесты разбора на сохранённых фрагментах страниц:

  ```bat
  .venv\Scripts\python.exe -m pip install -r requirements-dev.txt
  .venv\Scripts\python.exe -m pytest tests -q
  ```

- Ручная проверка на живом сайте: `.venv\Scripts\python.exe tests\live_check.py flow_flats`.
- Итоги исследования сайта — в `research/NOTES.md`.
