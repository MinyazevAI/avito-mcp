## 1. URL, город и категория

- Путь: `/{город}/{категория…}`. Город — слаг (`kazan`, `moskva`, `sankt-peterburg`, `nizhniy_novgorod`…).
- **Слаги категорий угадывать нельзя.** `/kazan/telefony/mobilnye_telefony` и `/kazan/telefony/mobile` → 404
  («Такой страницы не существует»). Рабочий путь — с хвостом-хэшем: `/kazan/telefony/mobile-ASgBAgICAUSwwQ2I_Dc`.
  Исключение: `/kazan/kvartiry/prodam` сам редиректит на `/kazan/kvartiry/prodam-ASgBAgICAUSSA8YQ`.
- **Надёжный справочник категорий есть в самой странице:** `window.__preloadedState__` (JSON внутри JS-строки),
  ключ `layout.header.categoryTree` — дерево из 592 узлов `{categoryId, id, level, name, url: "/all/…?cd=1", subs}`.
  Город подставляется вместо `/all/`. Справочник для сервера: `data/categories.json` (собирается `research/build_catalog.py`).
  В дереве нет подкатегорий «Услуг» (только сам раздел `predlozheniya_uslug`); их пути есть в
  `layout.footer.categoryTree` и ссылках на странице раздела, например
  `predlozheniya_uslug/remont_i_obsluzhivanie_tehniki-ASgBAgICAUSYC7T3AQ`.
- **Поиск только по тексту работает и сам выбирает категорию:** `/kazan?q=ремонт+стиральных+машин` →
  `/kazan/predlozheniya_uslug/remont_i_obsluzhivanie_tehniki/stiralnye_syshilnye_mashiny-…?q=…` (1 850 объявлений).
- `q`, `pmin`, `pmax`, `s` в категории работают: `/kazan/telefony/mobile-…?q=iphone+13&pmin=10000&pmax=30000&s=1`
  → Авито уточнил категорию до `/kazan/telefony/mobilnye_telefony/apple/iphone_13-…`, убрал `q`, а цену перенёс
  в `f=…`; 417 объявлений. `s=1` — по возрастанию цены (10000, 10000, 13500…). Другие значения `s` не проверены
  (меню сортировки в исходном HTML нет, открывается кликом по `sort/title`).
- Слаги ~10 крупных городов есть в футере: `[data-marker="footer/regions/seo-link"]` (`/moskva`, `/kazan`…).
  Для остальных городов — выбор города в интерфейсе (см. п. 4).
- Корень некоторых разделов — **витрина без выдачи и фильтров**: `/kazan/predlozheniya_uslug/remont_i_obsluzhivanie_tehniki-…`
  показывает плитки подкатегорий и карусели (160 `[data-marker=item]`, но без `search-filters`, без пагинации,
  без хлебных крошек). Фикстура `tests/fixtures/services_landing.html`. Инструмент должен это распознавать
  и предлагать подкатегории.

## 3. Панель фильтров

- Контейнер `[data-marker="search-filters"]` в левой колонке; **все фильтры сразу на странице**,
  кнопок «Все фильтры» / «Ещё фильтры» нет ни в одном из трёх сценариев. Есть только `params[ID]/show-button`
  («Показать ещё») — раскрывает длинный список вариантов внутри одной группы.
- Заголовок группы — `<h5>`; элементы размечены по схеме:

| Тип | Разметка |
|---|---|
| Флажки | `label[role=checkbox][aria-checked]` с `data-marker="params[ID]/checkbox/VALUE_ID"`; input `params[ID]/checkbox/toggle` |
| Переключатель | `label` с `data-marker="params[ID]/option(VALUE_ID)"` (и `option(all)`), а также `user/option(N)`, `footWalkingMetro/option(N)` |
| Список (select) | `select[data-marker="params[ID]/select"]` и `categoryId/select` (подкатегория), опции `…/option(ID)` |
| Диапазон | `params[ID]-from/input`, `params[ID]-to/input`; цена — `price-from/input`, `price-to/input` |
| Текст | `params[ID]/input` («Слова в описании») |
| Мультиселект с поиском | `params[ID]/multiselect-outline-input` (+`/input`, placeholder «Любой») — «Производитель», «Цвет» у телефонов; варианты в выпадающем списке (не исследован, см. «Открытые вопросы») |
| Где искать | `geoFilters/select` → попап `popup-location/*` |
| Одиночные флажки | `d/checkbox/1` («С Авито Доставкой»), `filters/withImagesOnly/withImagesOnly` |
| Сброс группы | `params[ID]-reset` («Сбросить») |

- Прототип `extract_filters.js` разбирает панель в компактный список (name, key, type, options, selected, from/to):
  квартиры — 38 групп, телефоны — 20, услуги (стиральные машины) — 11. Результаты: `research/dumps/*/filters_struct*.json`.
- Примеры групп:
  - **Квартиры:** Количество комнат (Студия, 1–4 + «Показать ещё»), Цена, Общая площадь, Этаж (+ Не первый/Не последний),
    **Год постройки дома** (диапазон `params[164901]`), Тип дома (флажки), Продавцы, Пешком до метро, Ремонт, Отделка, Площадь кухни…
  - **Телефоны:** Производитель (мультиселект), Память, Оперативная память, SIM-карты, Цвет, ОС,
    **Состояние** (Новое / Отличное / Хорошее / Удовлетворительное / Требуется ремонт — «б/у» = всё, кроме «Новое»),
    Цена, Продавцы (Все/Частные/Компании), **С Авито Доставкой** (`d/checkbox/1`), Авито Гарантия…
  - **Услуги (стиральные машины):** Техника (select), Услуга, Когда нужна услуга, Производители (флажки + «Показать ещё»),
    Кто оказывает услуги… **Фильтра цены и «Где искать» нет.**

### Применение фильтров — расходится с TASK.md

- **Кнопки «Показать N объявлений» нет: каждое изменение применяется сразу.** После кликов по флажкам и ввода
  в поля (с потерей фокуса) URL сам получил `?f=…&context=…`, счётчик сменился с 24 582 на 4 986, выдача
  перерисовалась без перехода на новую страницу. Состояние формы после применения читается обратно (проверено).
- Значит, `avito_apply_filters` должен: менять поля по одному с паузой, дожидаться смены URL/счётчика,
  в конце перечитать панель. Каждое изменение — отдельный фоновый запрос к Авито, поэтому паузы обязательны.
- Ссылка с готовым `f=` открывается напрямую и восстанавливает фильтры (используем как итоговый URL).
- `f` — base64url бинарного формата с вкраплениями JSON (`{"from":30,"to":null}`, `{"from":0,"to":12000000}`,
  `{"from":2006,"to":null}`). Вручную не собираем, как и сказано в TASK.md.
- Параметр `context=…` — служебный, в итоговом URL его можно отбрасывать.

## 6. Блокировки

- «Доступ ограничен: проблема с IP» бывает **двух видов**:
  1. слой поверх обычной выдачи (`[data-marker="portals-container"] > [role=region]`), при этом h1 и
     объявления на месте, а клики перехватываются слоем;
  2. отдельная страница: title «Доступ ограничен: проблема с IP», кнопка «Продолжить» → капча.
- Проверять нужно **весь** `innerText` и `title`, а не первые 3000 символов, как в старом server.py.
- После прохождения проверки страница сама не перерисовывается — URL нужно открыть заново.
- Блокировка началась после ~16 загрузок за ~40 минут (пауза 6 с) и **держится даже после успешного прохождения капчи**:
  пользователь проходил проверку несколько раз, но Авито тут же показывало её снова. Похоже на временную блокировку
  по IP/профилю. Не обходим. Для сервера: пауза по умолчанию 5–8 с, меньше лишних загрузок, при `blocked` —
  остановка и просьба к пользователю; советы README (без VPN, перерыв) актуальны.
- Перезагружать страницу, пока пользователь решает капчу, нельзя: это сбрасывает капчу.

## Этап 2: что выяснилось при проверке avito_open_search

- Доступ после блокировки восстановился сам примерно через час.
- При редиректе на уточнённую рубрику (`?q=iPhone 13` → `…/apple/do-30tr-…?f=…`) Авито сортирует выдачу,
  но теряет `s` в адресе. Сервер возвращает итоговый URL с восстановленным `s`.
- `s=2` — сначала дороже (проверено), `s=104` — по дате (Авито сохраняет параметр; дат в выдаче услуг нет,
  порядок не проверить). С `s=104` счётчик у услуг был 930 против 1 850 без сортировки.
- После того как Авито выбрал бренд Apple, в панели появилась группа «Модель» (тоже мультиселект).
- Транслитерация города по правилам Авито работает: «Набережные Челны» → `naberezhnye_chelny`.
- В шапке недвижимости город показан как «Казань, район, метро» — берём часть до запятой.

## Этап 3: что выяснилось при выставлении фильтров

- Каждое изменение фильтра обновляет выдачу за ~3 с (URL `?f=…`, счётчик); кнопки применения нет.
- Мультиселект («Производитель», «Модель»): после ввода текста в `params[ID]/multiselect-outline-input/input`
  прямо в панели появляется список флажков `params[ID]/list` → `label[role=checkbox]`
  `params[ID]/multiselect-button-checkbox(VALUE)/VALUE`. Кликать нужно по флажку, а не по тексту.
- Район: вкладка «Районы» в окне «Где искать», флажки районов; после сохранения в URL появляется
  `district=782` (Кировский), в поле — «Казань, 1 район».
- По тексту «iPhone 13» Авито само выставляет «Производитель: Apple» и «Модель: iPhone 13».
- Профиль `research/browser-profile` Авито блокирует надолго, тестовый профиль при этом работает.

## Фикстуры и приватность
